## Package Management

### `package.json`

**Location**: Root, and in each package/app

**Purpose**: Node.js package configuration

**Key Sections**:

#### Root `package.json`
```json
{
  "name": "kilo-code",
  "packageManager": "pnpm@10.8.1",
  "engines": {
    "node": "20.19.2"
  },
  "scripts": {
    "build": "pnpm vsix",
    "test": "turbo test",
    "lint": "turbo lint"
  },
  "workspaces": ["packages/*", "apps/*"]
}
```

**Important Fields**:
- `name`: Package identifier
- `version`: Semantic version
- `engines`: Required Node.js version
- `scripts`: Available commands
- `dependencies`: Runtime dependencies
- `devDependencies`: Development dependencies
- `peerDependencies`: Required by consumers

### `pnpm-workspace.yaml`

**Location**: Root

**Purpose**: Define pnpm workspace packages

**Configuration**:
```yaml
packages:
  - 'apps/*'
  - 'packages/*'
  - 'src'
  - 'webview-ui'
  - 'cli'
  - 'jetbrains/host'
  - 'jetbrains/plugin'
```

### `pnpm-lock.yaml`

**Location**: Root

**Purpose**: Lock file for exact dependency versions

**Usage**:
- Committed to repository
- Ensures reproducible installs
- Auto-generated by pnpm

### `.npmrc`

**Location**: Root

**Purpose**: npm/pnpm configuration

**Common Settings**:
```
shamefully-hoist=true
strict-peer-dependencies=false
auto-install-peers=true
```

## TypeScript Configuration

### `tsconfig.json`

**Location**: Root, and in each package

**Root Configuration**:
```json
{
  "files": [],
  "references": [
    { "path": "./src" },
    { "path": "./webview-ui" },
    { "path": "./cli" },
    { "path": "./packages/types" }
  ]
}
```

**Package Configuration Example**:
```json
{
  "extends": "@roo-code/config-typescript/base.json",
  "compilerOptions": {
    "outDir": "dist",
    "rootDir": "src",
    "composite": true
  },
  "include": ["src"],
  "exclude": ["node_modules", "dist", "**/*.test.ts"]
}
```

**Key Compiler Options**:
- `target`: ES2020
- `module`: ESNext
- `strict`: true
- `esModuleInterop`: true
- `skipLibCheck`: true
- `moduleResolution`: bundler
- `resolveJsonModule`: true

### Shared TypeScript Configs

**Location**: `packages/config-typescript/`

**Files**:
- `base.json`: Base configuration
- `cjs.json`: CommonJS modules
- `nextjs.json`: Next.js projects
- `vscode-library.json`: VS Code extensions

## Build Tools

### `turbo.json`

**Location**: Root

**Purpose**: Turbo build orchestration

**Configuration**:
```json
{
  "$schema": "https://turbo.build/schema.json",
  "pipeline": {
    "build": {
      "dependsOn": ["^build"],
      "outputs": ["dist/**", "out/**"]
    },
    "lint": {
      "cache": true
    },
    "test": {
      "dependsOn": ["build"],
      "cache": true
    }
  }
}
```

**Pipeline Tasks**:
- `build`: Build packages
- `lint`: Lint code
- `test`: Run tests
- `bundle`: Bundle for distribution
- `vsix`: Create VS Code package

### `vite.config.ts`

**Location**: `webview-ui/vite.config.ts`

**Purpose**: Vite build configuration

**Configuration**:
```typescript
import { defineConfig } from 'vite'
import react from '@vitejs/plugin-react'
import tailwindcss from '@tailwindcss/vite'

export default defineConfig({
  plugins: [react(), tailwindcss()],
  build: {
    outDir: '../src/webview-ui',
    emptyOutDir: true,
    sourcemap: true,
  },
  resolve: {
    alias: {
      '@': '/src',
    },
  },
})
```

### `esbuild.mjs`

**Location**: `src/esbuild.mjs`

**Purpose**: Extension bundling

**Configuration**:
```javascript
import * as esbuild from 'esbuild'

await esbuild.build({
  entryPoints: ['src/extension.ts'],
  bundle: true,
  outfile: 'dist/extension.js',
  external: ['vscode'],
  format: 'cjs',
  platform: 'node',
  target: 'node20',
  sourcemap: true,
  minify: process.env.NODE_ENV === 'production',
})
```

### `tsup.config.ts`

**Location**: Various packages

**Purpose**: TypeScript bundling

**Configuration**:
```typescript
import { defineConfig } from 'tsup'

export default defineConfig({
  entry: ['src/index.ts'],
  format: ['esm'],
  dts: true,
  clean: true,
  sourcemap: true,
})
```

## Code Quality

### `eslint.config.mjs`

**Location**: Root, and in packages

**Purpose**: ESLint configuration (flat config)

**Configuration**:
```javascript
import baseConfig from '@roo-code/config-eslint/base'

export default [
  ...baseConfig,
  {
    files: ['**/*.ts', '**/*.tsx'],
    rules: {
      '@typescript-eslint/no-explicit-any': 'warn',
      '@typescript-eslint/no-unused-vars': [
        'error',
        { argsIgnorePattern: '^_' }
      ],
    },
  },
]
```

**Shared Configs**:
- `@roo-code/config-eslint/base`: Base rules
- `@roo-code/config-eslint/react`: React rules
- `@roo-code/config-eslint/next`: Next.js rules

## CI/CD

### `.github/workflows/*.yml`

**Location**: `.github/workflows/`

**Purpose**: GitHub Actions workflows

**Common Workflows**:
- `ci.yml`: Continuous integration
- `release.yml`: Release automation
- `nightly.yml`: Nightly builds
- `publish.yml`: Marketplace publishing

**Example Structure**:
```yaml
name: CI
on: [push, pull_request]
jobs:
  test:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      - uses: actions/setup-node@v3
      - run: pnpm install
      - run: pnpm test
```

**Purpose**: Nix flake for reproducible environment

**Configuration**:
```nix

    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
  };

      buildInputs = [
        nodejs_20
        pnpm
      ];
    };
  };
}
```

## Summary

This reference covers the most important configuration files. Each file serves a specific purpose in the build, development, or deployment process. When making changes:

1. **Understand the purpose** of the configuration
2. **Check existing values** before changing
3. **Test changes** locally before committing
4. **Document significant changes** in commit messages
5. **Update this documentation** if adding new configs
